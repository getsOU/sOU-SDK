# sOU HUD SDK

Build your own CS2 HUD with HTML/CSS/JavaScript or C#/Blazor WebAssembly.

Start with the [HUD author guide](https://sou.sofc.dev/docs/hud-entwicklung). The SDK provides processed game and match data, editable HUD panels, starter projects and tools for creating installable `.souhud` packages.

Packages: SOU.Live.Contracts, SOU.Hud.Sdk, SOU.Hud.Tool and SOU.Hud.Templates.
